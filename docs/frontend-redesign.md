# 前端重构与重放说明

本次保留 Vue 3，重建工作台的导航、布局、树交互与重放入口。旧界面的问题主要是信息层级、长期占用首屏的配置表单、重复边框与渐变，以及阶段自动跳转中明确存在的 10 秒等待；这些不是 Vue 本身的限制。

## 原有要素与新入口

| 原有要素 | 本次入口与保留行为 |
| --- | --- |

| 保存、刷新、打开目录 | 配置操作区与工作台入口继续提供；运行中的不可变配置仍受原状态约束 |

已有任务配置继续沿用原数据结构；增加展示入口不要求用户迁移任务或重新配置模型。全局设置明确区分“显示名称”和“API 模型标识”；前者只供人识别，后者保持请求配置值。模型、角色、服务地址、环境与向量模型入口全部保留，原有输出 Token 最低 32768 的保存语义不变。

全局设置抽屉采用分类图标导航和白底表单，模型项以轻边框区分；支持键盘分类切换、对话框焦点约束、Escape 关闭和焦点恢复。任务操作区的保存、刷新与打开目录采用图标工具按钮，阶段执行、继续与中断保留图标和文字，原有启用条件不变。

任务文档和报告使用共用的安全 Markdown 渲染器，支持块公式与行内公式。KaTeX 仅在存在公式时加载，搜索树首屏不请求数学渲染资源；代码块保留原样，最终 HTML 经 DOMPurify 过滤。切换文档或回退重放会使未完成的旧渲染失效。

搜索图包含 Dagre 分层布局、融合来源虚线、拖拽平移、触控缩放、光标中心缩放、适配全图、定位选中/最优节点、重置、全屏、标签开关、搜索与动作/状态筛选、小地图导航。节点检查器按概览、方案、代码、结果、洞察和诊断组织，展示指标、有效性、交付状态、UCT、访问次数、耗时、父节点、融合来源及评估协议，并提供代码复制/下载。超过 100 个节点的布局在 Web Worker 中计算；手动移动相机会关闭自动跟随，避免拖拽与自动定位争夺视角。

任务定义审查未通过时，配置操作区显示“修复审查并继续”。该操作归档当前 AutoRealize 产物，保留数据认知和 QDI 的精确请求缓存，清除任务定义、合同、修补与最终审查缓存，再从任务定义检查点运行；通过后自动进入 AutoML。任务也可以选择“记录风险并继续下一阶段”，让任务定义、AutoML 代码审查和最终报告审查在各自有限重试耗尽后继续，并把风险写入 `review_gate_decision.json`、搜索节点诊断和报告告警。文件缺失、损坏证据、确定性合同缺陷、接口或安全预检失败仍会停止流程。

## 重放语义

重放是一条只读事件投影，不会再次训练、生成报告或调用模型 API。接口为 `GET /api/tasks/{task_id}/replay`；事件包含顺序、原始时间偏移、阶段、类型与状态变更。节点更新按替换处理，向后拖动后，未来的代码、得分、报告与最优节点不得残留。

- `recorded`：Gateway 保存实际观察到的状态变化，约每秒检查一次本地产物变化；观察间隔内未记录的变化不作推测。
- `reconstructed`：旧任务根据已有事件、节点创建/结束时间与最终产物保守重建。没有历史中间状态时不能伪装成完整逐步记录。
- `mixed`：记录开始较晚或最终捕获缺失时，合并已观察记录与明确标记的重建部分。
- 历史重建在阶段边界揭示最终产物；历史访问次数、累计奖励与 UCT 只在最终搜索快照出现，不把终局统计倒填进早期节点。
- 原始时间模式遵循实际事件偏移；节点节奏模式压缩长等待，可设置 1000 ms/节点，再叠加播放倍速。压缩节奏不是实际计算耗时。
- 重放接口清除密钥、授权字段与配置中的敏感内容；演示任务的节点、代码和指标均明确标记为示例，不能作为模型效果证明。
- 完整重跑写入明确的 `task_reset` 边界，重放只展示当前轮次，旧 JSONL 保留作为审计记录；继续搜索和中断恢复保留已有历史。后台捕获和前端轮询均过滤重跑、保存、删除后迟到的旧响应。
- 向后跳转时主图和小地图立即隐藏未来节点，迟到的 Worker 布局不能恢复未来内容；状态投影使用有上限的不可变检查点，加速长历史回退。

## 全流程与提示词

AutoRealize 产出可读的 Kaggle 风格任务描述与结构化执行合同，包含约束来源、假设、冲突、待确认项、合同标识及评估标识。AutoML 保持评价公式、方向、时间窗口、分组和验证划分一致；真正的集成使用对齐的留出或 OOF 预测并重新检查联合约束。预测、无状态求解器和 RL 分别使用适当的训练/推理接口。

大段任务背景与实现规则放在稳定前缀，节点代码、运行证据、剩余预算及当前动作放在后面，以利于兼容供应商的前缀缓存；缓存是否命中及节省幅度仍取决于供应商，不能仅凭提示词结构保证。模型备注名不替代实际 API 标识。

报告携带融合来源、评估协议与交付检查状态。只有协议匹配的候选才计算提升；缺少验证信息、不同划分或方向冲突不会被包装成确定收益。任务定义时未确定的算法与效果，可由后续实测证据解决；未被验证的业务假设仍需保留。

AlgoEvolve 新提交和恢复的动作共同受本次搜索尝试预算约束。生成或预检失败消耗一次尝试，但不伪装成成功节点；耗尽记录 `action_budget_exhausted`，无可选动作记录 `search_exhausted`，与 `steps_completed` 区分，之后仍可追加预算继续搜索。新生成和评审合同要求训练入口在新的产物目录中复用已选配置，导出训练依赖必须相对交付目录定位，缺失时不得静默回退其他参数。

报告首轮直接包含实际选中配置、解决方案内部试验、独立推理检查与确定性移交修复记录，即使补读轮次为 0 也可见。内部参数/算法试验不计作独立 MCTS 节点。`generation.max_prompt_chars` 限制 system 与 user 消息字符总数，优先保留运行证据，再对结构化档案和源码材料分配预算。服务可用 `AUTOREPORT_LLM_REQUEST_TIMEOUT_SECONDS` 与 `AUTOREPORT_LLM_MAX_RETRIES` 临时覆盖请求超时与尝试次数；未配置时沿用原默认值。

实际调用使用指定 `https://api.renice.cc/v1` 与 `gpt-5.6-sol`。小样本合成销售数据已完成任务定义、候选训练、独立进程推理、报告生成和报告审查；过程中发现并修复了合同字段、移交解析、接口预检和报告预算问题，通过缓存恢复和有记录的确定性移交修复继续验证，并非未经干预的一次完整生产运行。

本次只有 **1 个成功且可交付的 MCTS 节点**，实际选择 Ridge（`alpha=0.1`、一次时间趋势、种子 2025），候选代码报告固定验证集 MAE 为 **3.401584032374897**。拟合 20 行、验证 8 行、最终预测 6 行；MAE 未额外独立重算，不能作为业务精度承诺。同一节点内部比较了 4 组 Ridge 配置以及 Huber、Random Forest、Extra Trees、Gradient Boosting，这 8 组试验不计作独立 MCTS 节点。搜索因当时的预检误判中断，检查点保留；**本次没有真实完成 Fusion**，其逻辑由离线回归覆盖，界面 Fusion 演示使用明确标记的合成数据。

模型通过独立进程加载、无再训练推理、模型哈希保持、重复预测一致、输出行身份及与原提交一致等检查。原生成训练入口依赖 `selected_config.json`，缺失时会回退其他参数；本次交付另附绑定最佳配置的 `retrain.py` 适配入口及 `delivery_adapter.json` 来源/哈希记录，已在新进程和新目录重新训练，并得到与原模型一致的 6 行预测。原始代码与历史得分未改写。报告由指定模型完成分析、撰写、审查 3 次请求，明确区分内部试配与节点对比；训练适配在报告生成后补充，见交付说明。
