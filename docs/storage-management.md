# 本地存储管理

管理单位为数据文件夹、任务开发目录和代码包，不提供逐文件删除或归档。点击资源的真实路径会在服务所在机器的文件管理器中打开目录，大小来自实际目录扫描；多目录资源可展开查看各位置和大小。

「本地存储」按 **数据文件夹 → 任务 → 开发目录 / 代码包** 分组。数据项目页也显示该项目下的开发目录与代码包；算法模型包页按来源任务分组。无法可靠关联数据或任务的历史开发目录单独列出，不猜测归属。分组由登记的输入路径、任务链接和包的来源任务决定；同名任务不会合并。

可按数据、任务、路径、资源类型和归档状态筛选。资源行、任务组和数据组均可多选，批量执行归档、还原或删除。选择包含数据文件夹时，批量删除不可用。清理产物可先筛选「开发目录和代码包」再全选。按钮只显示动作名称，解释和影响范围放在点击后的确认窗口。

- **数据文件夹**只允许归档、还原，任何情况下都不允许删除。包括外部导入数据、放在运行目录内的输入、已归档输入，以及任务删除后保留的输入登记。
- **归档**隐藏记录，磁盘内容留在原位，不释放空间。归档数据项目时关联内容一起隐藏；「已归档」中可还原。开发目录和代码包支持分别归档。
- **删除开发目录**会实际删除任务运行目录、训练模型、生成代码、交付副本、试算和回放等关联产物，并移除任务及该任务发布的代码包。输入数据文件夹始终保留。
- **删除代码包**实际删除冻结发布副本及相关调用记录，保留来源开发目录。
- **删除历史开发目录**只删除确认窗口列出的独立目录。扫描会绕开已登记输入及任务目录，不把它们的上级容器重复列为删除对象。

永久删除需要先核对实际路径和大小、勾选确认，再执行；不会移入回收站。后台不接受客户端路径作为删除目标，数据保护在接口层强制执行，批量选择也不能绕过。输入目录的祖先、内部路径和符号链接别名均受到保护。旧项目 DELETE 接口固定拒绝删除，旧任务文件删除接口同样检查所有已登记输入。

执行中的任务、模型调用、对话和交付会阻止冲突操作。共用开发目录需要同时选择有关资源。确认令牌绑定资源关系和磁盘文件清单，十分钟后过期；内容变化或服务重启后需要重新确认。

统计不展开符号链接或目录联接，单目录硬链接内容只计一次。显示的是文件内容字节数；实际磁盘占用可能因压缩、硬链接等有所不同。确认窗口合并重叠路径，不能完整读取的目录会阻止删除。多目录删除失败时可能已有部分目录被删除，关联记录仍保留并报告错误，可重新核对后重试。

## 接口

- GET /api/studio/storage：目录与代码包索引，包括 data_id/data_name/data_path、task_id/task_name、can_delete 和归档状态。
- GET /api/studio/storage/{kind}/{id}：路径和空间统计；refresh=true 强制重新扫描。
- POST /api/studio/storage/open：打开该资源登记的真实目录。
- POST /api/studio/storage/preview：提交 resources: [{kind, id}] 和 action: archive|restore|delete，获得影响范围、阻止原因和确认令牌。
- POST /api/studio/storage/apply：提交相同选择和 confirm: true、confirmation_token。

kind 为 projects / datasets / tasks / packages / runs。projects 和 datasets 都是不可删除的输入数据文件夹；datasets 用于没有项目登记的任务输入。files 类型已移除。项目归档兼容入口为 POST /api/studio/projects/{id}/archive，还原入口为 POST /api/studio/projects/{id}/restore。

## 验证

后端测试仅操作 pytest 临时目录，覆盖原始输入保护（包含归档、批量、祖先目录和旧接口）、分组关联、物理删除、归档持久化还原、确认失效、共用目录、链接越界和写入失败。

浏览器脚本 frontend/decision-studio/e2e/storage_lifecycle_smoke.py 使用真实 Vue 构建和隔离 FastAPI TestClient，验证数据与任务分组、目录打开、空间统计、任务组多选、批量归档/还原、包和开发目录物理删除、原始数据哈希不变、刷新与移动布局。生产页面仅做只读检查。
